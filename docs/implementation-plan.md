## 3. 技術仕様

### 3.1 使用技術
- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **Chrome API**: chrome.history, chrome.storage, chrome.tabs, chrome.alarms
- **データベース**: Chrome Storage Local (IndexedDB は将来的に検討)
- **グラフ表示**: Chart.js (統計表示用)
- **UI フレームワーク**: 必要に応じて Bootstrap または Tailwind CSS

### 3.2 データ構造

```javascript
// ライフログエントリの構造
{
  id: string,                    // 一意のID (UUID)
  url: string,                   // ページのURL
  title: string,                 // ページのタイトル
  domain: string,                // ドメイン名
  timestamp: number,             // アクセス時刻 (Unix timestamp)
  visitDuration: number,         // 滞在時間 (秒)
  notes: string,                 // ユーザーメモ
  tags: string[],                // タグ（将来的な機能）
  isBookmarked: boolean          // ブックマーク済みかどうか
}

// 統計データの構造
{
  date: string,                  // 日付 (YYYY-MM-DD)
  totalVisits: number,           // 総訪問数
  uniqueDomains: number,         // ユニークドメイン数
  totalDuration: number,         // 総滞在時間
  topDomains: Array<{            // 上位ドメイン
    domain: string,
    visits: number,
    duration: number
  }>
}
```

### 3.3 設定項目
- `excludedDomains`: 除外するドメインのリスト
- `dataRetentionDays`: データ保持期間（日数）
- `autoBackup`: 自動バックアップの有効/無効
- `notifications`: 通知の有効/無効
- `privacyMode`: プライバシーモードの設定

## 4. セキュリティ・プライバシー考慮事項

### 4.1 データ保護
- すべてのデータはローカルに保存（クラウド送信なし）
- 必要に応じてデータの暗号化を実装
- ユーザーによる完全なデータ削除機能

### 4.2 権限の最小化
- 必要最小限のChrome API権限のみ要求
- 明示的な権限要求と説明

### 4.3 透明性
- データの収集・使用について明確な説明
- プライバシーポリシーの提供
